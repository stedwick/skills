# Calibration: what the user means by "finished"

Every editor, the referee and the judges read this file. It holds the user's real judgments. Add to it after every run.

## The rule

"The best designs are ones with constraints."

The last 20% is not mostly about whether things work. In the user's words, it is about "refining the design, tightening it up, and finishing it up into a cohesive page that doesn't go too far but remains creative and readable." Function checks matter, but they come second.
